# Paper Card: Focal Loss for Dense Object Detection (2017)

**arXiv ID:** `1708.02002` | **Domain:** Object Detection & Loss Functions
**Keywords:** focal-loss, retinanet, class-imbalance, object-detection, dense-detector

## 🎯 Problem Statement & Motivation
Resolves extreme foreground-background class imbalance in one-stage detectors by reshaping cross entropy loss with a modulating factor (1 - p_t)^gamma to down-weight easy examples and focus training on hard negatives.
