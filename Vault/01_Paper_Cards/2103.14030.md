# Paper Card: Swin Transformer: Hierarchical Vision Transformer using Shifted Windows (2021)

**arXiv ID:** `[[2103.14030]]` | **Year:** `2021`

### 🌐 Synaptic Knowledge Graph Links

## 🎯 Problem Formulation
Global self-attention in ViT has quadratic computational complexity $O(H^2 W^2)$ relative to image size, rendering it intractable for high-resolution dense prediction (detection and segmentation).

## ⚙️ Core Architectural Contribution
Hierarchical vision transformer with Shifted Windows (Swin) which computes local self-attention within non-overlapping windows and cross-window connections via cyclic shifting.

## 📐 Mathematical Formulations
$$
\hat{z}^\ell = \text{W-MSA}(\text{LN}(z^{\ell-1})) + z^{\ell-1}
$$
$$
z^\ell = \text{SW-MSA}(\text{LN}(\hat{z}^\ell)) + \hat{z}^\ell
$$
