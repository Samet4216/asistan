# Paper Card: Coordinate Attention for Efficient Mobile Network Design (2021)

**arXiv ID:** `2103.02907` | **Keywords:** mobile networks, attention mechanisms, coordinate attention, channel attention, positional information, ImageNet classification, semantic segmentation, COCO object detection

## 🎯 Problem Statement
Improving the performance of mobile networks by addressing the limitations of existing attention mechanisms, particularly the lack of positional information in channel attention.

## ⚙️ Proposed Method
Introducing coordinate attention, a novel attention mechanism that embeds positional information into channel attention to capture long-range dependencies while preserving spatial precision.

## 📊 Datasets & Empirical Results
- **Datasets:** ImageNet
- **Results:** The proposed coordinate attention outperforms existing methods like SE and CBAM in ImageNet classification and shows even better performance in downstream tasks such as semantic segmentation and COCO object detection.

## ⚠️ Limitations & Failure Modes
The computational overhead of the proposed method is minimal, making it suitable for mobile networks.

## 📝 Summary
The paper proposes a coordinate attention mechanism for mobile networks, which enhances the performance of classic mobile architectures like MobileNetV2, MobileNeXt, and EfficientNet without significant computational overhead. The method factorizes global pooling into two 1D feature encoding processes to capture long-range dependencies while preserving positional information.

### Eq. (4) Horizontal Spatial Coordinate Pooling
- **Mathematical Formulation:** $z_c^h(h) = \frac{1}{W} \sum_{0 \le i < W} x_c(h, i)$
- **Implementation:** `coordatt.py` (L25, L42)
```python
self.pool_h = nn.AdaptiveAvgPool2d((None, 1))
x_h = self.pool_h(x)
```
- **Technical Rationale:** Averages across horizontal width W, producing height-preserving coordinate feature [C, H, 1].

### Eq. (5) Vertical Spatial Coordinate Pooling
- **Mathematical Formulation:** $z_c^w(w) = \frac{1}{H} \sum_{0 \le j < H} x_c(j, w)$
- **Implementation:** `coordatt.py` (L26, L43)
```python
self.pool_w = nn.AdaptiveAvgPool2d((1, None))
x_w = self.pool_w(x).permute(0, 1, 3, 2)
```
- **Technical Rationale:** Averages across vertical height H, producing width-preserving coordinate feature [C, 1, W].

### Eq. (6) Joint Coordinate Feature Encoding
- **Mathematical Formulation:** $\mathbf{f} = \delta\left(F_1\left([\mathbf{z}^h, \mathbf{z}^w]\right)\right)$
- **Implementation:** `coordatt.py` (L45-L48)
```python
y = torch.cat([x_h, x_w], dim=2)
y = self.act(self.bn1(self.conv1(y)))
```
- **Technical Rationale:** Concatenates along spatial axis, applies 1x1 conv with reduction ratio r, batchnorm, and non-linear activation.

### Eq. (7 & 8) Directional Attention Map Generation
- **Mathematical Formulation:** $\mathbf{g}^h = \sigma\left(F_h(\mathbf{f}^h)\right), \quad \mathbf{g}^w = \sigma\left(F_w(\mathbf{f}^w)\right)$
- **Implementation:** `coordatt.py` (L50-L54)
```python
x_h, x_w = torch.split(y, [h, w], dim=2)
x_w = x_w.permute(0, 1, 3, 2)
a_h = self.conv_h(x_h).sigmoid()
a_w = self.conv_w(x_w).sigmoid()
```
- **Technical Rationale:** Splits joint representation back into H and W, projects back to original channel count, and passes through sigmoid.

### Eq. (9) Element-wise Multiplicative Modulation
- **Mathematical Formulation:** $y_c(i, j) = x_c(i, j) \times g_c^h(i) \times g_c^w(j)$
- **Implementation:** `coordatt.py` (L56)
```python
out = identity * a_w * a_h
```
- **Technical Rationale:** Applies coordinate attention maps multiplicatively over the original input feature map.
